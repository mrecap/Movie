Settings

Gemini API key

For this GitHub-only version, the browser must authenticate directly with Gemini. The key is not sent to GitHub or Apps Script. Google recommends server-side keys for public production apps, so use a restricted/private key and do not share this page with untrusted users.

Model

Why this version fixes the upload problem

The previous build asked Apps Script to create an upload session, then tried to use that session from another origin. This build creates and completes the Gemini upload entirely in the browser using the same API key and shows the real HTTP error if something fails.
